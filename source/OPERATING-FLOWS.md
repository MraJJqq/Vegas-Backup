# VEGAS V9 — 七大系统与共享基础设施

## 七大系统
1. **Logo**：品种标识、名称、倒计时和淡入淡出。
2. **背景**：独立背景层，当前底色保持 `#07110D`。
3. **行情卡片**：22个品种报价、滚动、拖动和点选。
4. **K线**：Gate数据、历史回补、实时更新、蜡烛绘制。
5. **EMA**：独立Canvas；唯一计算源为 `kline/ema-engine.js`。
6. **周期选择**：1H、2H、4H、8H、D。
7. **视窗**：拖动、缩放、最新端定位、历史位置恢复。

全屏动态适配、唯一品种目录、Gate访问层、IndexedDB缓存、生命周期与主运行协调层是共享基础设施。

## K线与EMA
```text
K线父容器
├── K线 Canvas：蜡烛和影线
└── EMA Canvas：七条Vegas均线
       ↑
共享视窗坐标、时间索引、DPR和价格映射
       ↑
统一K线数据 + 唯一EMA计算引擎
```
绘制层分离；EMA计算不重复，EMA层只消费计算结果。

## 数据规则
- Gate USDT永续；22个品种；五周期。
- 历史按时间分页，直到Gate实际历史边界；单次REST请求最多2,000根，不是总历史上限。
- 2H由相邻且对齐的两根1H聚合。
- D日线使用Gate REST `timezone=utc8`，不使用UTC0日线WebSocket。
- EMA：12、36、43、144、169、576、676。
- 不补造数据、不平移时间戳。
- IndexedDB不可用时暂停完整历史回补；保留最新行情展示并等待缓存恢复。

## 共享接口
- 品种目录：`modules/shared/instrument-catalog.js`。
- Gate合约池：`modules/shared/universe-v9.js`。
- 卡片报价与排序接口：`window.updateQuotes`、`window.setCardOrder`。
- K线、EMA共享父容器、视窗坐标、时间索引与DPR。
- 全屏动态适配只负责外层几何、安全区和横竖屏，不接管内部缩放。

## 生命周期与验收
页面隐藏时暂停请求、订阅、轮播和动画；恢复时重新启动。销毁时清理定时器、请求、订阅、观察器和监听器。验收覆盖品种/周期切换、空数据清屏、缓存失败恢复、日线时区、前后台、横竖屏和手势。
