# VEGAS V9

独立重建的Vegas行情网页。源码与素材基线来自 [MraJJqq/Media](https://github.com/MraJJqq/Media)，审计提交：`b859ec234d465538c0403a71fdfa71536e9cdb78`。

## 七大系统
1. Logo：品种标识、名称与周期倒计时。
2. 背景：独立背景层，保留 `#07110D` 基准色。
3. 行情卡片：22个品种报价、滚动布局与点选。
4. K线：Gate USDT永续历史/实时数据、蜡烛绘制和历史缓存。
5. EMA：独立Canvas绘制，统一计算引擎。
6. 周期选择：1H、2H、4H、8H、D。
7. 视窗：拖动、缩放、最新端定位和状态恢复。

全屏动态适配、Gate数据访问、IndexedDB、生命周期和页面协调层属于共享基础设施。

## 数据约束
- 仅使用Gate USDT永续真实数据。
- 22个品种，五个周期：1H、2H、4H、8H、D。
- 每个品种/周期分页获取交易所实际可提供的全部历史；单次REST请求最多2,000根，不设置总根数或年限上限。
- 2H由1H真实K线聚合；D日线按北京时间UTC+8。
- EMA参数：12、36、43、144、169、576、676。
- K线和EMA独立绘制，共享同一视窗坐标和时间索引。
- IndexedDB不可用时暂停全量历史预热，不误报历史完成。
